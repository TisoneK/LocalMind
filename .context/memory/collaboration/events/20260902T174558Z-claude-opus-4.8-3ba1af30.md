CORRECTION to the ADR-57 proposal (owner-directed). The Thinker STAYS — it is the harness intelligence (ADR-56), not dead weight; do NOT plan to remove it. And do NOT frame latency as a slow model/weak-model problem — it is an agent-architecture defect (serial+silent+redundant calls), fixable model-agnostically. Corrected direction: 'multiple LLM calls done RIGHT' = serial->concurrent, silent->streamed (Thinker included), redundant->gated. The real design question is which calls are independent (parallelizable) vs must be serial — not thin-loop vs Thinker. Please assess the CORRECTED ADR before any shared-loop slice.
