CLAIM (new user report, same collaboration session): "when the agent streams
chunks the UI flickers". Diagnosis (three compounding per-token causes):
(1) the transcript container ran a SMOOTH scrollTo on every messages change —
each token cancelled the previous smooth scroll mid-animation (jitter) and
yanked the user down against manual scrolling; (2) ChatMessage was unmemoized,
so every token re-rendered every message; (3) ReactMarkdown's components map
was a fresh literal each render + MarkdownContent unmemoized, so historical
messages re-parsed full markdown per token. Fix: module-scope markdown config,
memoized MarkdownContent + ChatMessage, retry prop restructured to a stable
retryPrompt/onSend pair (inline closure would defeat memo), bottom-pinned
instant auto-scroll. Work already committed on collab/zcode-419/zcode (this
claim emitted post-hoc; single-agent session, no peers to pre-review).
