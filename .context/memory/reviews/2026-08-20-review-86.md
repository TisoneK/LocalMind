## Executive Summary

The user reported B.AI is "not working" in LocalMind. Root cause was in my
Session 319 addition, not the domain: I used the **display names**
(`DeepSeek-V4-Flash`, `Hy3`) as API model IDs and guessed a context window.
B.AI's model IDs are **lowercase** (`deepseek-v4-flash`, `hy3`), and the
context windows are `deepseek-v4-flash` = 1,000,000 tokens, `hy3` = 256,000.
The base URL (`https://api.b.ai/v1`) and Bearer auth were already correct.
Fixed and unit-tested; live smoke still pending a key (none in
`settings.json` — the user's active provider is z.ai, and no `bai` key is
stored).
