# Session 200 Review — Remove Legacy Delegation Routing

## Executive Summary

LocalMind had two delegation systems. The modern ADR-8 path selected a scoped
parent agent and exposed `delegate`, `delegate_parallel`, and
`delegate_inline` as agent-owned tools. Separately, `_pipeline.py` invoked a
legacy `should_use_sub_agents()` keyword/complexity heuristic before the agent
loop, decomposed the request with a second framework, and returned its direct
chat output. That bypass contradicted the documented sole-router and
parent-agent architecture.

The legacy branch and its dedicated `core/agent/sub_agent.py` framework are now
removed. All cross-domain delegation must originate inside the selected parent
AgentLoop through scoped delegation tools.

## Discovery

- `_pipeline.py` had the only production caller of `should_use_sub_agents()`.
- `core/agent/sub_agent.py` was otherwise referenced only by obsolete P11
  tests and stale package documentation.
- Modern selection already routes by `primary_domain` through
  `select_agent_by_task_profile()`, and selected agents run through
  `BaseAgent.run()` → `AgentLoop.run()`.
- Coding and Research agents expose the modern `delegate` tool; Coding also
  exposes `delegate_parallel`.

## Changes

- Removed the pre-loop heuristic/decomposition branch from `_pipeline.py`.
- Deleted `backend/src/core/agent/sub_agent.py`.
- Replaced obsolete heuristic tests with regression coverage asserting the
  legacy module is absent and task-profile routing selects delegation-capable
  Coding/Research agents.
- Updated `AGENTS.md`, `docs/ARCHITECTURE.md`, `core/agent/__init__.py`, and
  the delegate tool documentation to describe the authoritative path.
