## Executive Summary

Third and last of the three surfaces the user screenshotted (Actions ✓
S210, Thought Process ✓ S211, Todos ✓ this session). The `TodoList` plan
checklist now reads like the reference agent's plan:

- the **currently-executing step is highlighted** — a running action
  under it, or a running/in_progress `todo.status`, gives it an amber
  ring, a spinner, and bold amber text (the reference's "current step");
- completed steps **animate their tick in**; steps **animate in** as the
  plan is built (framer-motion `AnimatePresence`); the progress bar eases;
- `prefers-reduced-motion` honoured.

Also fixed a structural issue that undercut the whole point: the Todos
section was **hidden while tools were running** (`LeftPanel` gated it on
zero active tool calls), so steps checked off invisibly. An existing plan
now stays visible during active work; only the empty "add a task" state
hides during work. The running-tasks indicator is unchanged.
