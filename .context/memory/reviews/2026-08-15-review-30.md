# Session 226 Review — B-2026-08-14-9 Agent Workspace as Canonical Live UI

- **Date:** 2026-08-15
- **Agent:** Super Z / GLM-5.2 (Z.ai cloud sandbox)
- **Core:** 0.5.0
- **Target:** ADR-34 B-9 — Agent Workspace as canonical live UI
- **Feature:** adr-34-realtime-workspace

## Problem

ADR-34 §4: "Agent Workspace is the primary live surface. Initialization
activates the Agents tab automatically. A normalized event reducer renders
parent and child nodes with public understanding, acknowledgement,
plan/todos, tool calls, evidence, verification, replan, errors, and
synthesis state."

The Agent Workspace existed but was passive:
1. The right panel defaulted to the **Observe** tab, not Agents.
2. When a turn started, the user saw the Observe pipeline, not the
   agent lifecycle.
3. The new B-7/B-8 events (`agent_initialization_ack`,
   `agent_initialization_understanding`, `evidence_to_parent`) were
   emitted by the backend but NOT rendered in the Agent Workspace.

## Fix

### 1. Auto-activate Agents tab on turn start (`RightPanel.tsx` + `WorkspaceLayout.tsx`)

Mirrored the existing `forceTerminalTab` pattern:
- `RightPanel.tsx`: added `forceAgentsTab?: boolean` and
  `onAgentsTabShown?: () => void` props, plus a `useEffect` that
  switches to the `'agents'` tab when `forceAgentsTab` is true.
- `WorkspaceLayout.tsx`: added a `forceAgentsTab` state + a `useEffect`
  that fires on the **rising edge** of "parent run is active" (uses a
  `prevParentRunning` ref to avoid re-firing on every render). Also
  auto-uncollapses the right panel if it's collapsed.

The rising-edge design prevents `forceAgentsTab` from fighting
`forceTerminalTab` — Agents fires once at turn start, Terminal fires
later when a shell/code_exec tool starts and takes priority.

### 2. Extended AgentRun type (`types/index.ts`)

Added three fields to `AgentRun`:
- `acknowledgement?: string` — B-7 model-owned acknowledgement
- `understanding?: string` — B-7 bounded thinker line
- `evidence?: EvidenceEntry[]` — B-8 evidence entries

New `EvidenceEntry` interface: `{ tool, iteration, evidenceChars, failed, timestamp }`.

### 3. SSE event handling (`useLocalMind.ts`)

Added three new `obs_event` handlers in the SSE switch:
- `agent_initialization_ack` → sets `acknowledgement` on the parent run
- `agent_initialization_understanding` → sets `understanding` on the parent run
- `evidence_to_parent` → appends an `EvidenceEntry` to the parent run's `evidence` array

All three use the existing `updateAgentRun` helper and the `rootRunId`
to target the parent run. No new state management pattern was introduced
— the existing `setAgentRuns((prev) => ...)` pattern is preserved.

### 4. Agent Workspace rendering (`AgentWorkspace.tsx`)

Extended the `RunNode` component to render the new fields inside the
expanded details section:
- **Acknowledgement**: green-tinted card with `MessageSquareText` icon
- **Understanding**: amber-tinted card with `Lightbulb` icon
- **Evidence entries**: monospace line per entry showing
  `evidence ← <tool> (N chars)` with a `failed` badge if the tool failed

Updated `hasDetails` to include `hasInitEvents || hasEvidence` so the
node auto-expands when initialization events or evidence arrive, without
requiring a user click.

## Open items / spillover

- **B-10 (next session):** now that the Agents tab is the canonical live
  surface, the Observe tab is redundant. B-10 will remove the Observe
  tab and its intent classification UI. The backend telemetry (stage
  timings, anomalies) should be folded into the Agent Workspace node
  details.
- The `agentRunsReducer` extraction (a proper `useReducer` instead of
  scattered `setAgentRuns` calls) was deferred — the current ad-hoc
  state updates work correctly, and a reducer refactor is a larger
  change that doesn't block B-9's user-facing value. It can be done
  in a future cleanup session.
- The `forceAgentsTab` fires on the rising edge of "parent running",
  which is correct for the normal flow. If a second turn starts while
  the first is still completing (rare, but possible with fast
  abort+resend), the ref correctly detects the new rising edge.
