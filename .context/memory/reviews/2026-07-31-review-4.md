# LocalMind Review — 2026-07-31 (Session 38)

## Scope

Continued the Tools audit by fixing the frontend chat transport defect recorded in Session 37: `streamChat()` retained the final SSE line when the response ended without a trailing newline, so the last token, error, or completion payload could be lost.

## Verified finding

`frontend/src/lib/localmind/client.ts::streamChat()` manually split decoded chunks on `\\n` and left the final partial line in a local buffer when `reader.read()` returned `done`. This was a real UI transport loss path, independent of backend routing or agent selection.

## Change shipped

- Extracted the line-oriented backend SSE contract into `frontend/src/lib/localmind/sse.ts`.
- Added `push()` for decoded stream chunks and `flush()` for the final unterminated line.
- Preserved `[DONE]` handling and CRLF normalization.
- Flushed `TextDecoder` state before flushing the parser, protecting UTF-8 sequences split across network chunks.
- Guarded completion so `onDone()` is emitted once whether completion comes from `[DONE]` or normal stream close.
- Added Vitest coverage for the exact no-trailing-newline regression and normal multi-event termination.
- Added the frontend `test` script and Vitest dev dependency/lockfile entries.
