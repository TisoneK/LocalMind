## Blocker: backend install fails on Windows

- **Symptom (user paste):** `pip install -e '.[dev]'` in `backend/` died at
  "Preparing editable metadata (pyproject.toml)" with
  `ValueError: Readme path must be within the project directory: ../README.md`.
- **Root cause:** `backend/pyproject.toml` referenced
  `readme = "../README.md"` and `license = { file = "../LICENSE" }` — hatchling
  forbids readme/license paths outside the project directory (every OS, not
  just Windows). The committed backend venv on the dev machine had a
  pre-existing `.pth` editable install and no `pip` binary, which is why this
  never surfaced locally.
- **Fix:** added `backend/README.md` (package-local README linking to the repo
  root) and `backend/LICENSE` (MIT copy); `pyproject.toml` now points at both.
- **Verification:** clean throwaway venv → `pip install -e '.[dev]'` metadata
  step "finished with status 'done'", wheel built, `Successfully installed
  localmind-0.5.16`.
