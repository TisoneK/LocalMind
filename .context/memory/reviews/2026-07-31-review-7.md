## Findings and Fixes

### High — Browser inspection capabilities were missing

Added `dom`, `network`, and `console` actions to the browser wrapper, including selector and request-filter support. Added the `browse` function schema to the agent loop so the model can generate these actions and preserve action-specific arguments through dispatch.

### Medium — Sensitive inspection output was not classified

DOM, network, and console inspection now return `RiskLevel.MEDIUM` because rendered page data, request URLs, and console messages can contain PII, credentials, cookies, or application secrets. Documentation instructs the agent to inspect only when needed and never submit sensitive data without permission.

### Medium — Browser output could exceed the context cap on failure

The final `ToolResult.content` is now bounded by the existing 8,000-character cap, including the action envelope, stderr, and truncation marker. Malformed model arguments are rejected before subprocess invocation.
