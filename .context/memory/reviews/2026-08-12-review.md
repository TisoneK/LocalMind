## Discovery (code-verified this session)

The architecture is NOT mis-laid-out: ADR-5 (closed loop), ADR-6 (multi-agent),
ADR-8 (agent-centric routing, Phases 1-4 shipped), ADR-10 (Observe→Think→
Decide→Act→Observe→Verify) already target the user's model. The gap is
**completion of the verification primitive**:

1. **Termination is model-asserted.** Every per-agent `is_done()` is a
   scaffold: `agents/{coding,browser,analyst,debugger,reviewer,verifier}/
   is_done.py` all return False. The loop ends when the model says "done" or
   the iteration cap fires.
2. **No goal contract.** No `Goal`/`success_criteria` object anywhere in
   `backend/src` — verification has nothing deterministic to check against.
3. **Verifier is a routing destination** (`Intent.VERIFY → verifier`), not an
   acceptance stage; `is_verifier_done` is a skeleton.
4. **Task state is scattered** across `ExecutionGraph`, `AgentTrace`, todo
   plan prose, and the objectives store — no first-class `TaskState`.
5. **No failure memory** — ADR-7's learning step was never wired into the
   runtime.

Real machinery that must not regress: playbooks reach the model
(`base_agent.py:315`), workspace feedback bar (`workspace_state.py`),
evidence-first Worker report + evidence gate, bounded delegation packets,
iteration caps + hit-limit fallbacks, check-before-acting injection, adapter
fixes, `_obs.all()`.
