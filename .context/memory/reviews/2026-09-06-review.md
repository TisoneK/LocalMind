# Review — 2026-09-06 — Session 425: visible decision-grade Thinker reasoning

## Executive Summary

The owner reported the agent's thinking as "too narrow and isolated, no
after-tool thinking, one sentence or small paragraph — it should think like a
human: precise, unique, helpful for decision making", refined mid-session to
"thinking should think about the task at hand and not expose agent's internals
or processes or terminologies". Root cause was architectural, not model
choice: the Thinker consults that ADR-57's latency gates kept were **drained
silently** (Session 324 contract), so the only visible thinking was the
model's own native reasoning — often nothing on free-tier passthrough models.
This session shipped ADR-57 slice 1's remainder (stream every call) plus a
decision-grade, task-focused prompt rewrite and turn-level continuity.
Unit-verified (34 tests, 7 new) and LIVE-verified on bankofai/qwen3.8-flash
with a before/after on the same prompt: consults surfaced **0 chars →
2189–2737 chars** of precise, evidence-named reasoning, with a clean
machinery-word scan and no JSON leak.
