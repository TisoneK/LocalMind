Ran the full LocalMind stack (backend :8000 + vite :3000, Chrome open at localhost:3000) and drove real turns through the web proxy. ## Root-cause findings (the diagnosis)

- z.ai free-tier **glm-4.5-flash with thinking ON sometimes streams only reasoning**: it thinks through the complete answer (visible in the ThinkingBlock), then emits just `"\n"`, `finish_reason=stop`, **no content, no tool call**. The adapter's Phase-1 debug showed a 157-chunk stream with 156 reasoning chunks and 1 content char — faithfully processed; the provider genuinely sent a content-less response.
- Verified 3/3 through the real adapter with one message variant; raw API with equivalent payloads answered ~every time (and the Session 256 nudge text produced a complete 131-char answer in a raw test). Payloads were byte-equivalent (captured via a temporary LM_DEBUG_DUMP). No 429s. Conclusion: **provider/model-side stochastic behavior on the free tier**, not a harness bug.
- The harness's bounded nudge is the right mitigation: when reasoning streams but nothing else arrives, nudge the model to continue; when it recovers, the turn completes.

## Changes

1. **`loop.py`** — `_MAX_EMPTY_REASONING_RECOVERIES` 1 → 2 (two continue-nudges before the honest evidence fallback; still bounded, think-only protection intact).
2. **Thinking-aware wall clock** — `REASONING_MAX_WALL_CLOCK_SECS = 360` (`constants.py`, env `LOCALMIND_REASONING_MAX_WALL_CLOCK_SECS` ≥ 180); Settings field `localmind_reasoning_max_wall_clock_secs` + settings.json load; `_effective_max_wall` scales when `adapter.thinking_enabled`; GET/POST `/api/settings/thinking` + Reasoning-section UI input. Rationale: a slow free tier spends 30-170s/call thinking, so 180s fits only ~1-2 calls — a recon+act+synthesize turn needs ~4-6 min. Per-call timeout, iteration cap, and recovery caps remain the spin protections (Session 32 contract: raising is allowed with a concrete reason; the 500-chunk Phase-1 cap + recovery bound + per-call 180s all fire before a spinning model can loop).
3. **`.env.example`** — documents `LOCALMIND_REASONING_MAX_WALL_CLOCK_SECS`.
