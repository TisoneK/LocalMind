## Fixes

### Issue 1 — observations updated only AFTER the final answer → FIXED (`c97b282`~1)
- **Cause:** during pending waits, `_drain_live_tool_events` (chat.py) flushed
  ONLY tool events; every other obs event (init/plan/thinker/loop lifecycle,
  Session-181 phase decisions, stage timings, intent, anomalies) stayed buffered
  in the collector until the next real TEXT chunk — which on an execute turn is
  the final answer. So the whole turn's narration landed at once at the end.
- **Fix:** `_drain_live_lifecycle_events` drains the non-tool remainder and emits
  the same obs_event SSE in the pending path, so phases + Observe metrics stream
  live. `drain()` clears only the pending queue, not `history()`, so the
  heartbeat status + end-of-turn workspace rebuild are unaffected. Live trace:
  lifecycle events stream before the answer token, with pending status_updates
  present.

### Issue 2 — Agent Workspace wiped every turn → FIXED (`c97b282`)
- **Cause:** `send()` (useLocalMind.ts) REPLACED `agentRuns` with a fresh
  single-parent tree each turn.
- **Fix:** ACCUMULATE per-turn run groups (finalize any still-running prior run,
  append the new tree, prune to the last 10 turns). Each turn is a numbered
  "Turn N" node; the active turn expands, prior turns collapse into their header.
