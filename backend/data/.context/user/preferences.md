# User Preferences (update in place)

How the user likes things done. Grows as sessions reveal preferences.

- **Communication:** direct, lead with the answer. Don't narrate reasoning
  unless asked. (inferred 2026-07-26)
- **Bug reports:** when reporting a bug, the user expects the agent to
  find and fix the root cause, not just the symptom. (confirmed 2026-07-26)
- **Architecture:** the user values structural audits over chasing bugs
  one at a time. "Stop chasing bugs, do a structural audit." (2026-07-26)
- **Testing:** the user values e2e behavioral tests over unit tests with
  clean inputs. "Running test files 100% successfully doesn't mean
  everything is perfect." (2026-07-26)
- **Workflow design:** the user's own .context/ system is the reference
  model. Workflows define constraints + checkpoints, NOT procedures.
  The agent has creative autonomy. (2026-07-27)
