- **Date:** 2026-08-20

- **Target:** "Drop b.ai and use bankofai.io" (B.AI in LocalMind "not working")
- **ADR:** ADR-55 (correction)

## Executive Summary

The user's B.AI provider was still broken for two reasons, both now fixed and
**live-verified** with the user's real key: (1) the canonical API domain moved
from `api.b.ai` to `api.bankofai.io` (b.ai → bankofai.io brand consolidation),
and (2) the user's `settings.json` still held the stale Session 319 model
`DeepSeek-V4-Flash`, which overrode the Session 320 lowercase default and is
why LocalMind kept returning `model_not_found`. The base URL was switched, the
stale runtime model was corrected, a misdiagnosed browser-User-Agent header was
removed, and an end-to-end smoke through the real adapter returned 38 models
and a correct `"PONG"` chat response.

## Discovery

- `settings.json` (`~/LocalMind/settings.json`) showed `adapter=bai`,
  `model=DeepSeek-V4-Flash` (stale/wrong case), `api_keys.bai` present.
- Live probing against `api.bankofai.io/v1/models` with the user's key:
  - Returns **38** model IDs, all lowercase: `deepseek-v4-flash`,
    `deepseek-v4-pro`, `glm-5.1/5.2/5.3`, `gpt-5.x`, `claude-*`, `gemini-*`,
    `kimi-*`, `qwen*`, `minimax-*`. **`hy3` is NOT in the live list.**
  - `POST /v1/chat/completions` with `deepseek-v4-flash` → 200, content `"OK"`.
  - `POST /v1/chat/completions` with `DeepSeek-V4-Flash` → **404
    model_not_found** (case-sensitive, re-confirmed).
- Cloudflare bot protection (403 "error code: 1010") is present but **only
  blocks the stdlib urllib `Python-urllib/*` UA**. `python-httpx/*`,
  `python-requests/*`, and `curl/*` all return 200 — so the backend's httpx
  client never needed a custom header. The browser-UA header added earlier was
  a misdiagnosis (the 403 came from the stdlib-urllib test scripts, not httpx).

## Fix Applied

- `openai_compat.py`: `base_url` `https://api.b.ai/v1` → `https://api.bankofai.io/v1`;
  removed the browser `User-Agent` header; display name →
  `BankOfAI (promo free models — time-limited)`; comments updated.
- `config.py`: B.AI comments updated (live-tested status + domain).
- `frontend SettingsModal.tsx` + `backend/.env.example`: label/comment updated.
- `tests/api/test_provider_registry.py`: base-URL assertion updated; the
  browser-UA test replaced with `test_bai_needs_no_custom_user_agent`
  (asserts `cfg.headers is None`).
- Runtime fix (outside the repo): `settings.json` `model` `DeepSeek-V4-Flash`
  → `deepseek-v4-flash` (atomic write, 0600 perms preserved).
