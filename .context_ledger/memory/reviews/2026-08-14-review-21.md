- **Target:** Extract the duplicated framer-motion enter + reduced-motion

## Executive Summary

Closes the realtime-alive-ui feature's implementation. Sessions 210–215
each re-inlined the same "fade + slide" enter animation and their own
`useReducedMotion()` call across five components. Extracted a single hook
**`useEnterMotion()`** (`frontend/src/lib/localmind/motion.ts`) returning
`{ reduce, enter }`:

- `enter({x, y, duration})` → spreadable `initial/animate/transition`
  props, with `initial: false` under reduced motion (item just appears);
- `reduce` is exposed so callers gate their other motion (pulses, pings,
  height collapses, framer `layout`) on the same preference.

Adopted in `ToolSteps`, `ThinkingBlock`, `TodoList`, `ActionHistory`,
`AgentWorkspace` — all drop their direct `useReducedMotion` imports.
**Behaviour-preserving.** Recorded as **ADR-30**. Bespoke non-enter
animations (scale-in ticks, width-animated bars, height collapses) stay
inline but still read `reduce` from the hook. The terminal's CSS-keyframe
cursor stays as-is (intentional, per ADR-30).
