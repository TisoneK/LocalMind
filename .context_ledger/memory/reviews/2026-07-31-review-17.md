# Review — Structured Delegation Instruction Packets and Isolated Child Runs

**Date:** 2026-07-31  
**Feature:** adr-8-agent-centric-routing  
**Scope:** fixed delegation instructions, isolated child run context, structured delegation results

## Delivered

- Added immutable `DelegationInstructionPacket` with objective, scope,
  constraints, forbidden tools, selected evidence, and output requirements.
- Added ephemeral `AgentRunContext` with unique child run IDs and parent-run
  correlation through task-local `ContextVar` state.
- Added bounded `DelegationResult` metadata with status, run identity,
  bounded output preview, output length, and error type.
- Extended the native `delegate` tool schema while preserving legacy
  `{target_agent, task}` calls.
- Child agents now receive only a literal delegated instruction packet rather
  than the parent's conversation or mutable trace.
- Forbidden tools are removed from standardized child allowlists; non-standard
  child agents default to no tools.
- Construction, configuration, child exception, timeout, and empty-response
  paths return correlated structured failure metadata.
- Parent evidence is bounded, marked as untrusted data in the child prompt,
  and excluded from returned metadata.

## Validation

- 87 focused backend tests passed across delegation and related agent suites.
- Changed Python files compile successfully.
- Ruff passed on all changed files, including the new delegation module.
- `git diff --check` passed.
- Independent code review: **Ship-ready — no blockers**.

## Remaining boundary

Delegation remains synchronous handoff in this slice. Parallel child execution,
frontend child-run panels, and migration/removal of the legacy `SubAgent`
framework remain separate follow-up work and are intentionally not mixed into
this change.
