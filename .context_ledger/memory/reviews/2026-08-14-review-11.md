# Review — Session 206: greeting fast path restored

## Executive summary

A user-facing trace showed that `Hi` entered the parent agent, spent more than
30 seconds in silent reasoning/tool activity, and behaved like a substantive
agent task. This violated the existing LocalMind contract that greetings are
handled directly without tools.

## Root cause

`core/trivial_input.py` still contained the deterministic greeting and direct
conversation helpers, but the Session 201 request-pipeline removal left
`AgentRuntime._process_unlocked()` with no production caller for them. Every
request, including `Hi`, proceeded to `ParentAgent.run()` with the full tool
surface.

## Fix

- Restored a runtime-level conversational boundary before memory/tool planning.
- Pure social inputs such as `Hi`, greetings, acknowledgments, and thanks use
  `trivial_response()`; greetings acquire no adapter and make zero provider
  calls.
- Clearly conversational questions use `conversational_response()` directly,
  without parent tool planning.
- Preserved persistence, stage timing, `turn_complete`, observations, token
  accounting, and the single final completion marker.
- Kept substantive requests on the one LocalMind parent-agent loop; this does
  not restore the deleted dispatcher or legacy sub-agent routing path.
- Added a regression proving `Hi` cannot acquire an adapter or invoke
  `ParentAgent.run()` and emits no tool events.
- Corrected stale runtime documentation and updated the public changelog.

## Validation

- Focused greeting/conversational tests: 54 passed.
- Full backend: 1752 passed, 2 skipped; 3 existing runtime warnings.
- Frontend: 141 tests passed.
- TypeScript and production build passed.
- Ruff clean for changed Python files.
- ESLint: 0 errors, 64 existing warnings.
- `git diff --check`: clean.

## Limitation

No new live-provider smoke test was run because local provider credentials were
not available. The zero-tool greeting guarantee is covered with provider and
parent-loop calls explicitly forbidden in the regression.
