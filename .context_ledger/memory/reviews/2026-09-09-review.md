## Discovery — the mechanism (read before trusting the item text)

The backlog entry attributed the behavior to "the gate's tool-evidence demand". Evidence shows the gate was a downstream actor, not the origin:

1. **OT-19 before-fix trace** (`scratch/edge-sets-2026-09-09-161122.json`, Otto S449; reproduced independently from my worktree at `…/…-170521.json`): the model's own visible reasoning said "No tools needed. The answer is teal" and the final answer WAS correct — yet the turn burned 4 tool calls creating the folder (shell `Test-Path` → failed cmd-quoting → `code_exec os.makedirs`), and the harness's final answer line carried `✓ 1/1 criteria met (folder created at C:/…/sessions/ott-OTT-19-…/convention)`. Stray empty dir verified on disk.
2. **No `create_plan` tool call happened.** `trace.success_criteria` was seeded by `agent_runtime.py:1560` calling `derive_goal_items(message, base_dir=<session workspace>)` — the Session-330 "fixed goal checklist" that runs on every parent turn.
3. **Deterministic reproduction (zero provider calls):** feeding the harness's exact `_long_needle_prompt()` into the pre-fix `derive_goal_items` returned `['folder created at C:/ws/sess-ott19/convention']` with sub-goals "check whether the folder … exists" / "create the folder … only if it is missing" / "verify … exists".
4. **The two flaws that made prose look like an instruction:**
   - Verb commitment used bare substring matching over the WHOLE message (`any(v in lowered for v in _FOLDER_VERBS)`): the phrase "every **new** hire" satisfied the "new" create-verb.
   - `_FOLDER_REF_RE` made the "called|named" marker optional, so "…then to a **folder convention** that everybody tolerated…" captured the name "convention" — a noun phrase in pasted content, three sentences from the only create-flavored word.
5. **Why the B-2026-09-09-2 gate-side class fix cannot cure this case:** the model DID run tools here, so "faithful zero-tool answer" is not the shape; the contract itself was invented. Derivation-side grounding is the disease-side fix. (Conversely the gate fix is still needed for its own symptom — the two items are complementary.)

## Fixes applied

- **`86ae1163` fix(agent)** — `derive_goal_items()`: verb matches are now word-boundary (`\bnew\b`, not `renew`) **and** the committing verb must sit in the same sentence as the file/folder token it names. False negatives remain safe by design (no derived deliverable → no contract → legacy path); false positives (fabricated contracts) are structurally gone. All prior positive shapes pinned by `tests/core/test_goal_derive.py` (23 tests) pass unchanged; +5 new regression tests (reading-prose negative incl. the exact OTT-19 sentence pair, cross-sentence verb leak, substring verb, same-sentence determiner positive, multi-sentence positive).
