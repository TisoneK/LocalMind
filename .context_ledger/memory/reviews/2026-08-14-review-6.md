# Session 201 Review — Parent-agent runtime replaces request pipeline

**Date:** 2026-08-14
**Feature:** `adr-8-agent-centric-routing`
**Scope:** remove the request-time execution pipeline and make LocalMind's parent AgentLoop the sole user-facing execution path.

## Findings

The former `core/engine/_pipeline.py` owned safety-adjacent lifecycle work and domain execution decisions in one large module. It also retained dispatcher classification, execution-graph/direct-tool branches, and legacy routing assumptions. That architecture made the product appear to be an LLM plus a tool selector rather than a decision loop.

## Changes reviewed

- Deleted `backend/src/core/engine/_pipeline.py`.
- Added `core.agent_runtime.AgentRuntime` as the lifecycle boundary and exported it through the compatibility name `Engine`.
- Added LocalMind's `ParentAgent` directory with its complete parent tool contract, parent context contract, and acceptance-gate stop condition.
- Threaded the existing `AgentLoop` instance through `BaseAgent`, preserving native tool calls, evidence observation, replanning, acceptance checks, abort, steering, persistence, memory, metrics, and SSE observability.
- Removed request-time dispatcher/graph/domain branches. `client_intent` is recorded only as a non-authoritative hint.
- Kept specialized agents and delegation tools intact; delegation starts inside the parent loop and child output remains internal to parent synthesis.
- Replaced pipeline-era routing language in active source/docs and added structural/runtime regressions.

## Architectural contract

```text
API/CLI → Engine compatibility export → AgentRuntime
        → ParentAgent → shared AgentLoop
        → native tools / scoped delegation → evidence → evaluate/replan → answer
```

`ThinkingDispatcher`, `ExecutionGraph`, and `WorkspaceOrchestrator` have no production request-path callers after this change. Their isolated modules remain available only for data-model/standalone tests and migration tooling; they do not select or execute tools for live requests.
