## Delivered

- `ExecutionGraph` now has a bounded read-only runtime contract admitting `WEB_SEARCH`, `WEB_FETCH`, and `SYSINFO` tool nodes, with task-local tool-policy enforcement.
- Tool argument serialization preserves common structured inputs, including `query` and `url`.
- Graph execution records failed `ToolResult`s as failed nodes, preserves provider failure details after retries, stops on required failures, marks pending dependents skipped, and emits wave/node observability.
- Graph evidence is bounded with an explicit truncation marker before synthesis.
- The engine executes only explicitly planned `MULTI_TOOL`/`MULTI_PHASE` graphs that pass validation and policy checks; invalid or mutating graphs fall back to the established agent path.
- Graph synthesis persists the assistant response, emits/stores observations, records provider token usage and failure-aware metrics, and provides an evidence fallback when model synthesis is empty.
- Graph-mode todos are emitted and their statuses reflect execution/synthesis success or failure.
- Added focused graph contract tests covering policy admission, invalid dependencies, URL preservation, dependency waves, required failures, policy blocking, and bounded evidence.
