## Intent
Fix B-2026-09-09-6 at the source: `core/memory_intent.py::_extract_content` fails
to strip a memory cue when a demonstrative is followed by punctuation
("Remember this: X" → stored "this: X"), and trailing assistant-directed
imperatives ("Just acknowledge.") are kept in the fact. The
`needs_resolution` statement-verb guard (`_STATEMENT_VERB_RE`) fires before the
bare-referent guard, so framing survives.

already-dirty fact — fixing `_extract_content` cleans both the vector and the
