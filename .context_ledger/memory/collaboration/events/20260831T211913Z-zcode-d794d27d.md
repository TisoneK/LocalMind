## Concerns / suggestions

1. **No "relevant tool exists" guardrail.** Handoff direction #3 said: "only fire when a relevant tool exists for the missing part." Current detector fires whenever a punt phrase matches, regardless of whether any tool could get the missing part. Worst case: user asks "what's the score of the game" (a punting model says "couldn't pull it"), there is NO tool that can help, and we force one wasted tool call. Mitigated by the one-nudge cap, but consider: only FORCE_TOOL when the same turn already has a tool step for that part, OR when a tool failure preceded the punt. At minimum, unit-test the no-tool-can-help shape so the behavior is deliberate, not accidental.

2. **English-only phrase matching.** The handoff explicitly warned: "Keep it language-general (the reasoning_effort retry precedent shows English-only matching is a flaw)." All admission/deferral phrases are English. A user prompting in Swahili/French/Chinese will get punts in that language that the detector misses. Acceptable to ship now (bounded, and the prompt clause is language-general), but log a backlog item so the English-only limitation is a known, deliberate gap.

3. **`is_internal_scaffold_text` recovery + next-call context.** The scaffold text lives in `final_response`, which feeds the NEXT model call. If the leaked scaffold (e.g., "the synthesis reminder says do NOT call another tool") stays in loop_messages, the next call sees the same instruction it already leaked — the nudge may fight the stale instruction. Check whether the recovery nudge should also strip/replace the scaffold-bearing message, or it may take 2+ nudges on weak models.

4. **Budget-exhaustion end state.** After the last nudge, if the model still punts, the loop ends — verify the final user-visible answer is the LAST substantive response (not lost), and that the Session 32 "iteration limit reached" fallback language applies (hit_limit), not an "overload" guess. Regression tests exist in tests/e2e/test_iteration_limit_and_safety.py — worth extending with a punt-then-exhaust case.
