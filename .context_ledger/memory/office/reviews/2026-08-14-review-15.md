## Executive Summary

First session of the `realtime-alive-ui` feature. Redesigned the chat
tool trace — the flagship "Actions" surface in the screenshots — from a
flat stack of one-card-per-tool into a single **grouped, animated,
live Actions timeline** that matches the reference agent's aesthetic:

- a **live natural-language summary header** ("Wrote 1 file, Ran 2
  commands") that updates as tools complete;
- a **connected vertical timeline** of steps with status dots;
- **framer-motion** enter animation per step as tools stream in, a
  pulsing running step + header, auto-expand while streaming and
  auto-collapse ~2.5s after completion;
- a **terminal row** — "Done" / "Done with errors" / live "working…";
- full `prefers-reduced-motion` support (transforms + pings disabled).

Per-step detail (why / input / output / code / file), compact mode, the
plan-step badge, and every `ToolCall` field are preserved. **No backend
change** — all data already streams over the existing SSE transport
(Sessions 205–209). Also closed a coverage gap: the trace component had
**zero tests**; added `ToolSteps.test.tsx` (9 cases).
