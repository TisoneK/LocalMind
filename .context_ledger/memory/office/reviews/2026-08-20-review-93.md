## Executive Summary

Two distinct problems in the trace, one ours to fix, one a free-tier model behavior:

1. **The premature stop is NOT a regression from the synthesized-todos change** — deepseek
   free-tier stopping after recon ("Let me create...") is the pre-existing S323-class failure; the
   todos change only added UI events and touches nothing in the loop's termination logic. Isolated
   harness runs showed the same stop before the todos change.
2. **But "2/2, 100%" is our artifact and a legitimate UI regression**: synthesized todos = "tools
   that ran", so a recon-only stop now LOOKS complete. The panel counts plumbing, not task
   outcomes.
3. **The deeper bug is real and worse than the panel**: "Let me create the path-test folder and
   the two files" was ACCEPTED as a final answer. The S323 creation-commitment detector
   (`_is_tool_talk` in `text_tools.py`) was built for narration BEFORE a tool call, and its
   adjective group `(\w+ )?` cannot match hyphenated or dotted tokens — "path-test folder" and
   "a.txt"/"b.txt" break it, so the commitment text sails past detection.

## Root cause (code)

- `text_tools.py` `_TOOL_TALK_PATTERNS`: the creation-commitment pattern's optional adjective
  group `(\w+ )?` only matches word characters — hyphenated ("path-test") and dotted ("a.txt")
  tokens fail to match, so `(\w+ )?folder` cannot consume "path-test folder".
- The tool-talk check runs on the streamed response regardless of tool calls (loop.py ~3815), so
  the ONLY reason this slipped through is the pattern miss — confirmed by a direct call: the exact
  reproduction returns False while the S323 original ("source modules") still returns True.

## Fix (`93d59d6`)

- Widen the adjective group to cover hyphenated/dotted tokens: `(\w+(?:[.\-]\w+)* )?` — the exact
  reproduction ("path-test folder", "a.txt"/"b.txt") is now caught; S323's original case preserved;
  safe negatives stay safe (unit-checked before the edit).
- Regression test added in `tests/core/test_dsml_interception.py` with the user's exact sentence.

- This does NOT make a recon-only stop complete the task — the stop itself is model behavior; the
