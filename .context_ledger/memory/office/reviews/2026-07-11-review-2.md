| # | File | What it had | Lines |

| 1 | `adapters/openai_compat.py` | `PROVIDER_CONFIGS` — `ProviderConfig(name, base_url, api_key, default_model)` | ~150 |

**Drift risk:** Adding a provider required updating all 7. Missing one would silently break that provider's model routing, settings display, or adapter construction.

**Conflict found:** `zen` had `default_model="minimax-m2.5-free"` in `PROVIDER_CONFIGS` but `"gpt-4o-mini"` in `PROVIDER_INFO`. The `PROVIDER_CONFIGS` version was more recent (Zen was updated to use minimax-m2.5-free). This is exactly the kind of drift the duplication causes.

## What was fixed (Phase 3)

### Approach

Extended `ProviderConfig` with the fields the other modules needed (`key_env`, `model_env`, `settings_field`, `display_name`), then derived every other structure from `PROVIDER_CONFIGS` via dict comprehensions.

### Changes (commit `e2c0258`)

1. **`adapters/openai_compat.py`** — `ProviderConfig` dataclass extended with `key_env`, `model_env`, `settings_field`, `display_name`. All 19 provider entries updated with the new fields. Added 4 derived registries: `CLOUD_PROVIDER_NAMES`, `PROVIDER_SETTINGS_FIELDS`, `PROVIDER_MODEL_ENVS`, `PROVIDER_KEY_ENVS`.

2. **`adapters/__init__.py`** — `get_adapter()` now checks `CLOUD_PROVIDER_NAMES` (derived) instead of a hardcoded 19-name tuple. Error message derives the list too.

3. **`api/routes/config.py`** — `PROVIDER_INFO` replaced with a dict comprehension over `PROVIDER_CONFIGS`. Added `VALID_ADAPTERS` and `ADAPTER_MODEL_FIELDS` (both derived). `get_settings()` and `set_adapter()` use the derived maps.

4. **`core/model_router.py`** — `provider_model_map` derived via `{key: getattr(settings, cfg.settings_field, "") for key, cfg in PROVIDER_CONFIGS.items()}`.

5. **`backend/pyproject.toml`** — Added `E402` ignore for `routes/config.py` (the `PROVIDER_CONFIGS` import must come after the Pydantic models above it).

### Conflict resolved

`zen.default_model`: kept `"minimax-m2.5-free"` (from `PROVIDER_CONFIGS`, the more recent value) rather than `"gpt-4o-mini"` (from the stale `PROVIDER_INFO`).
