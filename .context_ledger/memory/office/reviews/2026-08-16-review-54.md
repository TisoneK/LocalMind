## Trigger

## Architecture clarified (the user's mental model is correct)
- It is NOT tool-to-tool routing. The `AgentLoop` is the orchestrator in the
  middle: each iteration the model decides ONE (or several) tool calls → dispatch
  → observation → the Thinker reasons on the evidence → next iteration → synthesis.
- "Intent" is a ONE-TIME upfront classification that picks the turn's PERSONA
  (prompt template) + TOOL SCOPE — not a route between tools. My "routing" wording
  in B-9 was wrong; corrected.

## Concurrency — mostly already there
- **Parallel tool calls already work:** when the model emits several tool calls,
  the loop dispatches them concurrently via `asyncio.gather` (loop.py:1603); tools
  carry `parallelizable` metadata (stateful ones like code_exec opt out).
- **Honest caveat:** a model cannot keep GENERATING tokens while awaiting tool
  results — its turn pauses at the tool hand-off and resumes when results are sent
  back. So "keep thinking/planning while tools run" isn't literal; the achievable
  version is: parallel dispatch (done) + narration + surfacing each result AS IT
  COMPLETES instead of blocking on the whole `gather`. The as-completed streaming
  is a real enhancement → B-2026-08-16-10.

## Narration — built, with a live-found catch
The model's `content` alongside a tool call IS the narration (chain-of-thought
comes separately on the reasoning channel). The loop was routing that content into
the ThinkingBlock (obs "thinking"), and prompt rule 869.2 said "never narrate —
just call". Fix: the loop now streams that content to the user's CHAT (both single-
and multi-tool paths); the prompt asks for ONE short user-facing line.

**Live-found catch (glm-4.5-flash):** it emitted 374 thinking tokens then EMPTY
content — so there was no narration text to stream. Narration only appears when a
model produces content. Per the user ("naturally when thinking the narration is
not there"), that is the intended behavior: the ThinkingBlock is the update during
reasoning; narration appears in chat when the model narrates. NOT synthesizing fake
narration (rejected the Thinker-as-narrator and tool-templated options).
