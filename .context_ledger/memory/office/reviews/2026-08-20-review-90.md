## Executive Summary

The ADR-42 Thinker — the loop's silent, read-only mid-turn analyst — was streaming its raw reasoning into the
user-visible Thinking block on every model. Because no filter-before-render step existed, `loop.py` forwarded every
`thinking` chunk from `Thinker.consult()` straight to the SSE thinking stream. The user's screenshot showed the model
echoing the Thinker's own system prompt ("You are the Thinker — SILENT and READ-ONLY…", "Output: … EXACTLY ONE JSON
object"), musing about the JSON structure it must emit, and reasoning about loop-internal corrective nudges ("The user
request is meta: …"). The consult's `_JSON_MARKERS` filter only stopped at the JSON tail — all the prose before it
surfaced.

**Fix shipped (`db5bfdc`):** the Thinker consult is now truly silent — it buffers the model's output internally for
parsing only and yields no user-visible chunks; the loop drains it and the render boundary is explicit. The structured
analysis still drives the agent (injected into the model's context), survives for the degraded-evidence fallback
(`trace.thinker_analysis`), and the lifecycle stays visible via `agent_thinker_start`/`done` obs events.

## Discovery

- Traced the leak: `thinker.py::consult` yielded `StreamChunk(thinking=...)` for prose up to the first JSON marker;
  `loop.py:3110` forwarded `_tc.thinking` to the user's SSE thinking stream. On a thinking model (deepseek-v4-flash
  via bankofai reports `thinking_enabled=True`), the model's reasoning — which commonly restates the prompt — rendered
  wholesale into the Thinking block.
- The "bled-in unrelated example" from the user's transcript was not cross-session bleed: `Evidence.user_message`
  takes `_user_message_text(loop_messages)`, which after a tool-talk/forced-tool recovery is the corrective nudge
  itself, so the Thinker reasoned about it. Internal correctness; the confusion was purely the visibility, now fixed.
- The "still wired to bankofai, not dropped" flag is a misunderstanding: Sessions 319-322 RENAMED bai → bankofai
  ("drop b.ai" = drop the b.ai domain for api.bankofai.io), they did not remove the provider. It is intentionally the
  active provider under test; the footer "deepseek-v4-flash · bankofai" is correct.

## Fixes Applied

1. **`thinker/thinker.py`** — `consult()` buffers `chunk.text + chunk.thinking` internally for parsing and yields no
   thinking chunks; removed the `_JSON_MARKERS`/`_first_marker`/`_visible_len` surfacing machinery (it existed solely
   to filter a stream that should not exist). Docstring updated to the silent contract.
2. **`loop.py`** — drains the consult (`async for _tc in ...: pass`); removed the `yield StreamChunk(thinking=...)`
   forwarding. Updated the ADR-42 comment to document the render boundary.
3. **Tests** — `test_thinker.py`: `test_consult_is_silent_but_parses_analysis` (nothing surfaced; analysis still
   parsed/attached). `test_tool_force_recovery.py`: loop-level `TestThinkerStreamSilent` — with a thinking-enabled
   adapter and real tool evidence, the Thinker consult runs but its reasoning never reaches the user's stream.
