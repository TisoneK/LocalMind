# Review 69 — Session 300: direct capability turns felt slow and generic

- **Date:** 2026-08-19
- **Agent:** Buffy | **Model:** openai/gpt-5.6-luna | **Platform:** macOS (Darwin, local) | **Role:** engineer | **Core:** 0.8.0
- **Task:** User shared a real transcript where `Hi`, `What can you do?`, and `Like what` took 15–30 seconds, repeated generic capability prose, and accumulated roughly 8k prompt tokens. Diagnose the live path rather than trusting compatibility regression tests.

## Root cause

The live `AgentRuntime` explicitly sent every turn through the model-owned parent initializer. The existing `core.trivial_input` conversational fast-path helpers were documented as compatibility-only and were not called by the live runtime. As a result, obvious social turns and stable capability FAQs paid for a GLM JSON initialization call. The capability answer was also left entirely to a weak model, which produced a broad inventory and then repeated it for `Like what`.

## Fix

- Restored a runtime fast path for obvious greetings, conversational questions, and capability FAQs when there are no attachments or explicit tool restrictions.
- Kept ambiguous, tool-bearing, and attachment turns on the parent-agent path.
- Added deterministic, concise capability answers for `What can you do?` and concrete example expansion for `Like what?`.
- Preserved the existing observation contract: initialization/loop lifecycle events, all five stage timings, turn completion, persistence, metrics, and workspace artifacts remain truthful on the fast path.
- Added focused detection, answer, contextual-follow-up, runtime no-provider-call, and stage-observability coverage.

## Real GLM A/B verification

Used the established Claude live harness: isolated settings/home, real z.ai
`glm-4.5-flash`, thinking enabled, shell enabled, port 8765, same task,
logs/SSE inspected directly.

- **Before (committed HEAD):** `What can you do?` entered parent initialization,
  used `init_prompt_chars=3519`, took **19,956 ms**, sent **930 prompt tokens**,
  and returned a generic **404-character** inventory.
- **After (working tree):** the same task made **no provider call**, returned a
  categorized concrete answer in **2 ms**, used **12 estimated prompt tokens**,
  and emitted `fast_path=true`.
- **Follow-up after:** `Like what?` also completed in **2 ms** with **0 provider
  calls**, returned distinct examples, and emitted truthful stage timings:
  `intent_classify/context_build/tool_select/execute=skipped`,
  `generate=done`.

A first full-gate run caught missing stage timing events; that was fixed before
shipping. Final full CI: **1998 backend passed / 2 skipped**, Ruff clean,
frontend TypeScript clean, ESLint 0 errors / 71 existing warnings. Final live
smoke confirmed the fast-path event and stage-timing contract after that fix.
