# Review — Session 205: live parent-agent interaction during slow tools

## Scope

The user reported that LocalMind appeared detached during long tool/model calls:
the UI showed no meaningful agent activity for more than 30 seconds, and tool
results only appeared after the engine yielded its next model chunk.

## Root cause

`chat.py` consumed `Engine.process()` with a plain `async for`. The SSE bridge
could not inspect `ObsCollector` while the engine was blocked awaiting a tool or
provider response, so its existing keepalive comments did not provide visible
agent interaction.

## Implementation

- Added a shielded `_with_keepalives()` iterator that waits with a timeout
  without cancelling the pending engine/tool operation.
- Added selective `ObsCollector.drain_matching()` so heartbeat flushing removes
  only tool/terminal events and leaves planning, metrics, and other observations
  for the normal bridge.
- Heartbeats now forward parent `tool_call` progress and bounded parent results,
  plus terminal events, before the next model chunk arrives.
- Reused the existing `_visible_tool_output()` boundary: delegated child raw
  output remains hidden while parent-owned tool output remains visible.
- Added live action-store recording for heartbeat-flushed tool events.
- Added tests for selective draining, heartbeat-time progress, visible parent
  output, and delegated-output privacy.
- Updated the public changelog.
